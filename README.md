# Rivals Original

A fresh, original tactical arena shooter built for Roblox.

This project is a new start inspired by the energy and flow of shooter arena games, but designed with a distinct identity: cleaner structure, stronger round logic, original maps, and a more polished competitive feel.

## Core idea

- Arena combat with fast respawns
- Original weapons and movement feel
- Clean HUD with scoreboard and match flow
- Competitive lobby and live-round states
- Future room for cosmetics, maps, and ranked progression

## Project structure

- `src/ReplicatedStorage/Shared/Config.lua` - gameplay settings and weapon balancing
- `src/ReplicatedStorage/Shared/Remotes.lua` - remote events for client/server sync
- `src/ServerScriptService/GameServer.server.lua` - match flow, combat, and round logic
- `src/ServerScriptService/WorldBuilder.lua` - map generation and arena layout
- `src/StarterPlayer/StarterPlayerScripts/GameClient.client.lua` - HUD, input, and player feedback
- `docs/PROJECT_BLUEPRINT.md` - original game design notes and progression plan

## Goal

Create a realistic, clean-feeling arena shooter with strong presentation, responsive controls, and a polished competitive experience while staying original instead of copying any one game outright.
